# Contributing

Thanks for helping improve Bountiz.

## Issues

Use the issue forms for reproducible bugs and focused feature requests. Report security
vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

## Pull requests

1. Fork the repository and create a focused branch from `main`.
2. Install Node.js 24+ and pnpm 11+.
3. Make the smallest coherent change and add focused tests when behavior changes.
4. Run `pnpm check`.
5. Open a pull request that explains the problem and solution.
